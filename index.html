// why

Why it exists

A filter that only uses DNS stops working the moment something goes around it. A browser with Secure DNS, or any VPN, resolves names on its own, and the block quietly disappears.

The hosts file sits below all of that. Windows checks it before any name resolution, so the block holds no matter which browser, VPN, or resolver you use. This is why BloBlocker combines both layers.

// usage

Three steps

  1. Run the installer "BloBlocker-Setup.exe" and install to Program Files
  2. open BloBlocker from the desktop icon and accept the Administrator prompt
  3. press Activate. Protection is now live

The installer creates a desktop shortcut, a Start menu entry, and an uninstaller you can find in Apps & Features.

// faq

Questions

Does it collect data?

No. Everything runs on your device and the app never makes a connection.

Can a VPN bypass the block?

It can get past the DNS layer, but not the hosts layer. Windows always checks the hosts file first, before any network call.

Why does it ask for Administrator?

Editing the hosts file and system DNS settings requires elevated rights.

Windows flags the download as a virus?

This is a false positive that shows up with unsigned Python-built executables. The installer is new, so Windows has not learned to trust it yet. You can report it to Microsoft as a false positive; see the README for details.

SmartScreen says "unknown app". Is it safe?

Yes. The installer has no digital signature yet, so Windows treats it as unknown until it earns trust from downloads. To continue, click "More info", then "Run anyway".

  1. Click "More info" on the warning window
  2. Click "Run anyway"
  3. The install finishes and a desktop icon appears
